# Fonts

이 디렉터리는 1min.dev 웹사이트에서 자체 호스팅하는 Pretendard 글꼴 파일을 보관합니다.

- **글꼴명**: Pretendard
- **버전**: 1.3.9
- **제작자**: Kil Hyung-jin (orioncactus)
- **출처 (저장소)**: https://github.com/orioncactus/pretendard
- **라이선스**: SIL Open Font License 1.1 (자세한 내용은 `OFL-1.1.txt` 참조)

## 포함된 파일 및 굵기

- `Pretendard-Regular.woff2`: 굵기 400 (Regular)
- `Pretendard-SemiBold.woff2`: 굵기 600 (SemiBold)
- `OFL-1.1.txt`: SIL Open Font License 1.1 전문
